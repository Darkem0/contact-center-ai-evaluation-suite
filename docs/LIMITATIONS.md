# Limitations

- The default engine uses small English lexical rules; it is not a trained classifier or an evaluation benchmark.
- “NPS” is only a task-pack label for generic root-cause signals. The output never estimates a survey score.
- Factuality is not verified because the demo has no source-of-truth corpus; potentially certain wording is merely routed for review.
- The API lacks authentication, authorization, rate limiting, retention policy, observability, fairness analysis, and human-review workflow.
- Do not use this sample for personnel, customer, legal, compliance, financial, or safety decisions.
